A make.fun entry for "Real Life Patch Notes: The Comedy Changelog": one funny,
single-line software patch note for a bug in real life / human biology.

Running `main.ts` (Node 22) writes the entry to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), with no
trailing newline:

```sh
node main.ts
```
